# 星空影像馆 · STARRY ARCHIVE · 360° 作品穹顶

整站只有一页:一个 360° 球面画廊,展示 34 张已收录视觉作品,载入先缩放推进视角、再展开图片,可拖拽旋转、点击看大图。减少动态效果时直接显示完整布局。
求职版不设置空位；返回入口可继续浏览个人作品集。

星云和星点位于封闭的三维球面，与照片共用相机。拖拽、惯性和自动环游保持同步，横向可连续旋转，纵向可接近天顶与脚下。这是鼠标或触屏操作的 360° 全景，不依赖 VR 头显。

背景配色包含蓝紫银河、玫瑰色气体云、暖金与蓝白恒星。八颗不同大小的艺术化行星分布在全景各方向，含带环气态星、海洋星、岩石星和冰星；全部位于照片外侧，不占用作品位置。材质和球面细节由本地 WebGL 生成，不需要额外下载图片。

## 打开

请在整个 Felix 网站的项目根目录运行 `npm run dev`,然后在浏览器访问:

```text
http://127.0.0.1:52125/portfolio/index.html
```

必须走本地服务器 —— 直接双击 index.html 会被浏览器安全策略拦截(ES Module)。
库(three.js / GSAP)全在 `vendor/`,离线也能跑,不连任何 CDN。

## 改站名 / 分类 / 数量

全在 `app.js` 顶部 `CONFIG`:
- `brand` 站名(环形文字);左上角水印、页脚署名在 `index.html` 里搜 `JUNTING` 改;
- `cats` 分类名(VISUAL);
- `counts` 每类作品位置数量,现为 34 个视觉位置，与已收录图片数量一致。

## 调手感

同样在 `CONFIG`:球半径 `radius`、视角 `fov`、拖拽 `dragK`、惯性 `inertia`、自转 `autoSpin` 等,每项都有注释。

## 换成真照片

图片放在 `images/`，在 `collection.js` 按固定位置编号登记 `src`、原图宽高 `w` / `h`、图片描述 `title`。球面缩略图和点击大图共用这一条记录，未登记的位置继续使用占位卡；不改变球面布局或拖拽方式。

当前展示 34 张（a-001 至 a-034），保留原图及图内文字。增加图片时同时调整 `counts`，避免出现空位。GitHub 开发项目另以独立列表呈现在主站作品区。
